## Welcome
Welcome to Cobalt In-App Documentation. This is where you'll find helpful 
documentation that will guide you through your Cobalt app experience.

### What You Should Know
There are three things you should know:

 1. Documentation is easy to access. Just click the little <i name="help-circle"></i>
 icon in the user bar. Any documentation for your current page will be displayed.
 2. Use the index search if you're unsure.
 3. You can [write your own documentation]({{@route("Cobalt\Documentation\Controllers\Documentation@__index")}}) for custom apps.
